Operators: operadores

Contas, comparações e lógica em Python.

Arithmetic operators

We use them to do math.

OperatorNameExampleResult
+plus7 + 29
-minus7 - 25
*times7 * 214
/division7 / 23.5
//floor division7 // 23
%remainder7 % 21
**power2 ** 38
  • / always gives a float: 10 / 2 is 5.0.
  • // gives the whole part of the division.
  • % gives what is left. Example: 7 divided by 2 is 3, and 1 is left.
  • int + int = int. If one number is a float, the result is a float.

Comparison operators

They compare two values. The answer is True or False.

OperatorMeaningExampleResult
==equal to5 == 5True
!=not equal to5 != 3True
>greater than5 > 3True
<less than5 < 3False
>=greater than or equal to5 >= 5True
<=less than or equal to3 <= 2False

Be careful: = saves a value (x = 5). == compares two values (x == 5).

Order of operations

Python does some operators first: **, then * / // %, then + -. Then comparisons, then not, and, or.

2 + 3 * 4
(2 + 3) * 4

20

Tip: use parentheses ( ) when you are not sure.
