Data structures: estruturas de dados

Lists, tuples, dictionaries e sets: como cada uma guarda dados.

Lists

A list keeps items in order. You can change it: add, remove or replace items.

colors = ["red", "green", "blue"]
colors[0]
'red'
fruits = ["apple", "banana", "cherry"]
fruits[0] = "mango"
fruits
['mango', 'banana', 'cherry']
tasks = []
tasks.append("Write report")
tasks.append("Call John")
tasks.insert(0, "Pay bills")
tasks
['Pay bills', 'Write report', 'Call John']
MethodMeaning
.append()adds an item at the end
.insert()adds an item at a position
.remove()removes the first item with that value
.pop()removes and returns an item
.sort()sorts the list
.reverse()reverses the list

The first item has index 0.

Tuples

A tuple is like a list, but you can’t change it (it is immutable). Use it for fixed data.

coordinates = (10.5, 20.3)
person = ("Alice", 30, "Engineer")
person[2]
single = (5,)
'Engineer'

The comma makes the tuple. A tuple with one item needs a comma: (5,). Tuple methods: .count() and .index().

Dictionaries

A dictionary keeps pairs: a key and a value. Keys are unique. You use the key to find the value.

person = {"name": "Alice", "age": 30, "city": "New York"}
person["name"]
person["age"] = 31
del person["city"]
person
'Alice'
{'name': 'Alice', 'age': 31}
MethodMeaning
.get()gives the value of a key (or a default)
.keys()all the keys
.values()all the values
.items()all the key-value pairs
.update()adds or changes pairs
.pop()removes a key and gives its value

Sets

A set keeps unique items. It has no order. It removes duplicates.

fruits = {"apple", "banana", "cherry"}
"banana" in fruits
visitors = ["Alice", "Bob", "Alice", "Charlie", "Bob"]
set(visitors)
empty_set = set()
True
{'Charlie', 'Bob', 'Alice'}

The order of a set can change. Use set() for an empty set. {} makes an empty dictionary.
