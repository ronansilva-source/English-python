Printing, conditionals e loops

Mostrar resultados, tomar decisões e repetir tarefas.

Printing variables

Use print() to show something on the screen.

name = "Ana"
age = 20
print("Hello")
print(name)
print("My name is", name)
print(f"{name} is {age} years old.")
Hello
Ana
My name is Ana
Ana is 20 years old.
  • With a comma, print() puts a space between the items.
  • An f-string is the easiest way to put variables inside text.
print("a", "b", "c", sep="-")
print("Hi", end="!")
print(" Bye")
a-b-c
Hi! Bye

sep changes what goes between the items. end changes what goes at the end (the normal end is a new line).

Conditionals

A conditional runs code only if a condition is true. We use if, elif and else.

x = 7
if x > 5:
    print("x is greater than 5")
x is greater than 5
grade = 60
if grade >= 70:
    print("Pass")
elif grade >= 50:
    print("Recovery")
else:
    print("Fail")
Recovery
  • The line with if ends with a colon :.
  • The code inside is indented (4 spaces). Indentation is part of Python’s syntax.
  • Python checks from top to bottom. It runs the first block that is true.
  • else has no condition. It runs when nothing above was true.

Loops

A loop repeats code.

for loop

A for loop goes through each item of a collection.

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
apple
banana
cherry

In each round, the variable fruit gets the next item.

for i in range(3):
    print(i)
0
1
2

range(3) gives 0, 1 and 2. It stops before 3.

while loop

A while loop repeats while the condition is true.

count = 0
while count < 3:
    print(count)
    count += 1
0
1
2

count += 1 means count = count + 1. If the condition never becomes false, the loop never stops!

break and continue

for n in range(5):
    if n == 1:
        continue
    if n == 3:
        break
    print(n)
0
2
  • continue skips this round and goes to the next.
  • break stops the whole loop.
