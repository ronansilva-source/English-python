Type casting

Type casting means to change one type to another type.

  • int(3.9) gives 3. Python cuts the decimals. It doesn’t round.
  • int("abc") gives an error (ValueError), because "abc" isn’t a number.
  • int("101010", 2) reads the text as base 2 and gives 42.

Why is this useful?

input() always gives a string. Change it to a number if you want to do math:

age = int(input("Your age: "))
print(age + 1)

f-strings

name = "Ana"
age = 20
f"{name} is {age} years old."
'Ana is 20 years old.'

Strings are immutable: a method like .upper() gives a new string. The old string stays the same.

List comprehensions

A list comprehension is a short way to make a list from another list.

With a for loop

squares = []
for x in range(5):
    squares.append(x ** 2)
squares
[0, 1, 4, 9, 16]

With a comprehension (same result)

squares = [x ** 2 for x in range(5)]
squares
[0, 1, 4, 9, 16]

Pattern: [what_to_do for item in collection]

With a condition

even = [x for x in range(10) if x % 2 == 0]
even
[0, 2, 4, 6, 8]

Real example: binary to decimal

binary_strings = ["1101", "1010", "1111"]
decimal_numbers = [int(b, 2) for b in binary_strings]
decimal_numbers
[13, 10, 15]
