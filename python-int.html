Python: o tipo int

Texto da referência do Real Python, reescrito em inglês simples.

What is an int in Python?

An int is a type of data in Python. "Int" means "integer".

An integer is a whole number. It doesn't have a decimal point. Examples: 42, -5 and 0.

An integer can be positive, negative or zero.

Why do we use integers?

  • We use them to count things. (3 books, 10 students)
  • We use them to find the position of an item in a list.
  • We use them to do math: plus, minus, times.

Code example

number = 42
type(number)    # <class 'int'>

The type of 42 is int.

Same number, different bases

In Python, we can write the same number in four ways:

decimal     = 42
binary      = 0b101010
octal       = 0o52
hexadecimal = 0x2A

All of them are 42. Only the way we write the number is different. The number is the same.

Make an int from a string

int("101010", 2)    # 42

The 2 means "base 2" (binary). The string "101010" becomes the number 42.

Some methods of int

  • .bit_length() → how many bits the number needs.
  • .bit_count() → how many ones the number has in binary.
  • .to_bytes() → changes the number to bytes.
  • .from_bytes() → changes bytes to a number.

Real example

We have three binary strings. We want decimal numbers.

binary_strings = ["1101", "1010", "1111"]
decimal_numbers = [int(b, 2) for b in binary_strings]
# [13, 10, 15]

1101 is 13. 1010 is 10. 1111 is 15.
