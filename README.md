# English com o Ronan

Site estático (HTML + CSS) com o guia de Inglês 1, rotina de conversação, prompt para o ChatGPT e o texto adaptado sobre `int` em Python.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `ingles-ronan`).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em Settings → Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. O site abre em `https://SEU-USUARIO.github.io/ingles-ronan/`.
