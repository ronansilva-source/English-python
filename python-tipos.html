Data types: tipos de dados

Integers, floats, strings, booleans e None, em inglês simples.

Integers

An integer is a whole number. It has no decimal point. It can be positive, negative or zero.

number = 42
negative = -5
zero = 0
type(number)
<class 'int'>

Read the full text in Python: o tipo int.

Floats

A float is a number with a decimal point.

1.5
float("3.14")
float(42)
1e-3
1.5
3.14
42.0
0.001
  • float("3.14") changes a string to a float.
  • float(42) changes an int to a float: 42.0.
  • 1e-3 is scientific notation. It means 0.001.
  • Int + float = float. Example: 1.0 + 2 is 3.0.
  • Division with / always gives a float: 10 / 2 is 5.0.

Strings

A string is text. We write it between quotes. Strings can’t be changed after we create them (they are immutable).

greeting = "Hello, World!"
single = 'Hello'
double = "Hello"
multi = """Line one
Line two"""
f"The number is {42}"
'The number is 42'

The f before the quotes makes an f-string. Python puts the value inside {}.

Booleans

A boolean has only two values: True or False. Comparisons give booleans.

5 > 3
5 == 3
bool(0)
bool(1)
bool("")
bool("hi")
True
False
False
True
False
True

Some values count as false: 0, "" (empty text), [] (empty list) and None. Most other values count as true.

Null: None

None means “nothing” or “no value”. It is the Python way to say null.

result = None
result is None
type(None)
True
<class 'NoneType'>

Use is None to check it (not == None).
